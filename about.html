About strudel-bench

  • Strudel is the browser live-coding environment for patterns. Its code says what to play: a sample name, a note list, a filter cutoff in hertz.
  • strudel-bench is a small language on top of Strudel, and this site and repository for writing songs in it. Its code says what a song should sound like: five layers (drums, bass, melody, pad, fx), twelve axes from 0 to 1 where 0.5 is each layer's baseline, and a vocabulary of words ("darker", "punchier", "a bit more dreamy") that move several axes at once. A song is a list of sections, each with its own layer settings and its own key and progression, and every song reduces to plain Strudel. The bench plays songs, shows the source next to the Strudel it expands to (regenerated as you type), exports MP3 and Strudel, and holds the command-line tools that check, edit, render and measure a song without a human listening.

Why the bench exists

It is an experiment in letting a coding agent make music it cannot hear. An agent editing plain Strudel has to guess what a cutoff change does. In strudel-bench, "make the drop brighter" is a numeric edit in one place, and the bench can render the song before and after and compare the spectral centroid. That is the feedback loop the whole project is built around: change a word, check the event stream, render, measure, report what moved. The repository holds a script for each step (check, resolve, render, analyze, verify) and a test suite that pins the exact event stream of every song, so an edit that changes something it should not is caught before anyone listens.

Most of the code and the songs were written by coding agents working from a written spec, in the spirit of the author's blog: always shippable, always improving.

What is on this site

  • Compose: pick a song, play it, edit the source, export an MP3 or the expanded Strudel. On this hosted copy songs you create or save live in your own browser; nothing is uploaded.
  • Examples: a playable card for every axis, descriptor, modifier, harmony word and section edit, with the high-level source and the Strudel it expands to.

How it is built

Node standard library and a plain textarea. No bundler, no framework, no build step beyond copying files. Strudel's own packages run in the browser; the same library files run under Node for the checker and the tests. Sample packs come from the Strudel CDN (the same ones strudel.cc uses); local packs can be added as folders and ship only when their license says so. Source and issues: github.com/jonborchardt/strudel-bench.
